# Design System - Anshika Enterprises

## Color Palette
- **Primary**: `#4A90E2` (Brand Blue)
- **Secondary**: `#F5A623` (Brand Orange)
- **Background**: `#F8F9FA` (Off-white)
- **Surface**: `#FFFFFF` (White)
- **Text Primary**: `#2C3E50` (Dark Slate)
- **Text Secondary**: `#7F8C8D` (Cool Gray)
- **Error**: `#E74C3C` (Red)
- **Success**: `#2ECC71` (Green)

## Typography
- **Font Family**: Inter, Roboto, or System Default
- **H1**: 32px, Bold
- **H2**: 24px, Semi-Bold
- **H3**: 20px, Medium
- **Body**: 16px, Regular
- **Caption**: 12px, Regular

## Layout & Spacing
- **Base Unit**: 8px
- **Padding (Small)**: 8px
- **Padding (Medium)**: 16px
- **Padding (Large)**: 24px
- **Border Radius (Small)**: 4px
- **Border Radius (Medium)**: 8px
- **Border Radius (Large)**: 16px

## Components Rules
- **Buttons**: Should have Medium Border Radius (8px) and Medium Padding (16px).
- **Cards**: Should have Surface Background (`#FFFFFF`), Large Border Radius (16px), and a subtle shadow.
- **Inputs**: Should have a 1px solid border matching Text Secondary, Small Border Radius (4px).
